# 어느 날 내가 로판 주인공이 되었다 — 배포 안내

정적 사이트 1개 + 신청 접수 함수 1개로 되어 있습니다. 빌드 과정이 없어서 그대로 올리면 됩니다.

```
index.html        테스트 본체 (이미지·영상·폰트 모두 내장)
api/apply.js      신청서를 노션 DB로 보내는 함수
og.jpg            카톡·인스타 링크 미리보기 이미지
favicon.png       탭 아이콘
vercel.json       캐시·보안 헤더
```

---

## 1. Vercel에 올리기

**방법 A — 드래그앤드롭 (제일 빠름)**

1. [vercel.com/new](https://vercel.com/new) 접속
2. 이 폴더(압축 푼 상태)를 통째로 끌어다 놓기
3. Deploy

**방법 B — CLI**

```bash
npm i -g vercel
cd 이폴더
vercel          # 미리보기 배포
vercel --prod   # 실제 배포
```

---

## 2. 노션 연결 (신청 접수)

이걸 해야 신청 버튼이 작동합니다. **안 하면 신청할 때 "전송이 안 됐어요"가 뜹니다.**

### 2-1. 노션 통합 토큰 만들기

1. [notion.so/my-integrations](https://www.notion.so/my-integrations) 접속
2. **새 API 통합** → 이름은 아무거나 (예: `로판테스트`) → 워크스페이스 선택 → 저장
3. **내부 통합 시크릿**을 복사 (`ntn_` 으로 시작)

### 2-2. 데이터베이스에 통합 연결하기

1. 노션에서 **로판 테스트 신청자** 데이터베이스 열기
2. 우측 상단 `⋯` → **연결** → 방금 만든 통합 선택

> 이 단계를 빠뜨리면 토큰이 있어도 권한 오류가 납니다.

### 2-3. Vercel에 환경변수 넣기

Vercel 프로젝트 → **Settings → Environment Variables**

| 이름 | 값 |
|---|---|
| `NOTION_TOKEN` | 2-1에서 복사한 `ntn_...` |
| `NOTION_DB` | `41fe3e44917181cc91a7f7e97b99a8f3` |

넣은 뒤 **Deployments → 최신 배포 → Redeploy** 를 눌러야 적용됩니다.

> `NOTION_DB` 값은 노션 DB 주소에서도 확인할 수 있습니다.
> `notion.so/41fe3e44917181cc91a7f7e97b99a8f3?v=...` 에서 `?` 앞의 32자리.

## 3. 배포 전에 채울 것

`index.html` 상단의 `CONFIG` 부분입니다. 에디터에서 `const CONFIG` 로 검색하세요.

```js
const CONFIG = {
  instagram: "@your_account",   // ← 운영 계정으로
  paymentUrl: "",               // ← 15분 초과 유료 상담 결제 페이지 주소
  deadline: "2026-10-31",       // ← 신청 마감일 (D-DAY 자동 계산)
  apiEndpoint: "/api/apply",    // 그대로 두세요
};
```

`instagram` 값은 결과 카드 이미지에도 찍힙니다.

## 4. 확인

배포 후 아래를 차례로 보세요.

- [ ] 테스트를 끝까지 하고 신청서를 제출 → 노션 DB에 행이 추가되는지
- [ ] 카톡에 링크를 붙여넣어 미리보기 이미지가 뜨는지
- [ ] 휴대폰에서 BGM 버튼(좌측 하단)이 켜지고 꺼지는지

노션에 들어 있는 **샘플 신청자** 행은 지우셔도 됩니다.

---

## 참고

- 신청 데이터는 서버 함수를 거쳐 들어갑니다. 토큰은 브라우저에 노출되지 않습니다.
- 전송에 실패하면 화면에 **"전송이 안 됐어요"**가 뜨고 다시 보낼 수 있습니다.
- 함수 로그는 Vercel → 프로젝트 → **Logs** 에서 볼 수 있습니다.
